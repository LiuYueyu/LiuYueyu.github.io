# 星座网络运行状态监控平台

本版本继续针对右侧信息输出区进行了闭环修复，重点解决“网络状态”和“资源状态”显示不全的问题。

## 本次修改
- 网络状态框高度单独增大，不再被其它信息框挤压。
- 网络状态卡片改为内部垂直居中，标题和值都固定单行显示。
- 资源状态框高度单独增大，资源环和文字说明不再超出外框。
- 资源环区域取消错误的固定高度计算，改为自适应占满父容器。
- 在低高度屏幕下单独设置网络状态和资源状态的压缩规则，保证仍能完整显示。
- 保持整体一屏显示，不引入页面下滑。

## 使用方式
解压后直接打开 `index.html` 即可运行。

## 主要功能
- 左侧输入控制：星座构型、轨道数、每轨卫星数、相位因子、轨道高度、轨道倾角、观察视角、图层显示。
- 中间动态运行视图：程序绘制地球、轨道、卫星节点、星间链路、地面链路。
- 右侧信息输出：支持全局信息 / 单星信息切换。
- 支持鼠标悬停卫星查看详情并高亮相关轨道与链路。

## 2026-07-02 顶部运行状态条闭环修复
- 针对运行图上方“网络时间 / 运行时长 / 仿真状态”显示不全问题，已统一调整运行状态条高度、宽度、内部图标尺寸和文字行高。
- 网络时间改为紧凑时间格式，顶部右侧仍保留完整日期时间。
- 对运行状态条、网络状态框、资源状态框、右侧卡片和图表面板做了统一防裁切约束，避免只压缩外框导致内框超边界。

## 2026-07-02 运行图比例修正
- 运行图已加入地球半径模型：默认采用 **地球半径 6371 km**。
- 卫星轨道半径按 **轨道半径 = 地球半径 + 轨道高度** 计算。
- 默认 520 km 低轨场景下，轨道相对于地球表面的高度按真实比例体现，不再使用与地球半径无关的经验半径。
- 地面站投影改为位于地球表面，即按地球半径绘制。
- 右侧“网络状态”中同步显示地球半径、轨道高度和轨道倾角。

## 本次更新：运行图鼠标拖拽旋转
- 运行视图支持鼠标左键拖拽旋转。
- 水平拖动调整观察经度，垂直拖动调整观察纬度。
- 拖拽后观察视角自动切换为“自定义”，并同步更新左侧经纬度输入框。
- 画布光标调整为 grab / grabbing，并禁用触控默认滚动，便于触摸板或触控屏拖拽。


## 本次补充优化
- 运行视图中的地球已升级为更强科技感的程序化背景效果，包含全息光晕、经纬网格、扫描带、球面数据连线、节点光点与外层HUD环。
- 仍然为前端程序绘制，不依赖截图地球图。

- 地球渲染已调整为更接近前面参考图的蓝色真实感球体：深蓝海洋、柔和大气光晕、云带、弱经纬网格和夜侧城市光点。
- 已弱化上一版过密的HUD矩阵和数据连线效果，整体更接近参考图里的发光地球背景。
- 地球仍为 Canvas 动态绘制，不使用截图。
